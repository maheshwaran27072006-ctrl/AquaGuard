AquaGuard demo (simulated data)
1. Extract this ZIP.
2. Open the aquaguard_demo folder.
3. Double-click index.html, or in PowerShell from this folder run: start .\index.html
4. Use the sidebar to test Dashboard, Leak Reports, Maintenance and Analytics.
5. Export CSV to create aquaguard-reports.csv for a future Strands Harness agent.

This is a front-end demo only. It does not connect to real sensors or send real alerts.
